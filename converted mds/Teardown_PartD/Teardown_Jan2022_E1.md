Useful Features
Touch Up appearance – Users can change their appearance by

Break-Out Rooms – This helps users engage in discussions in

Screen-Sharing – Users can share their screens during the
meeting to show multiple screens
Whiteboarding – Host can enable a whiteboard which can be
used by participants if granted permission
Live Language Interpretation – Foreign languages is translated
via live interpreter. Limited languages are available as of now.

Solutions
Zoom Calendars – In app calendar which will track the
schedule of individual users. Will send reminders before each
meeting.
Meeting Summary – This feature will display a summary of
the meeting discussion at any point during the discussion.
Smart Chat – AI driven chat where users can get their
questions answered. Users can send pictures without
attaching; have separate tabs for Q&A, chat and media.
Smart Monitoring – AI can be used to track attentiveness of
participants. Host/speaker can gauge if audience is able to
comprehend the discussion.
Smart Mute – Users will be unmuted/muted when they
speak/not speak.

Advanced Presentation – Multiple participants will be visible
on the screen with a shared slide deck as their background.
Each participant can control the slide.
Video Edit – Basic video editing options can be provided like
trim, crop, etc.
Separate breakout rooms – Host will be able to see all the
breakout rooms on the single zoom screen and will be able to
talk to them after unmuting them individually. Host does not
have to move through different breakout rooms separately.
